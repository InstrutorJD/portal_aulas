🧰 Prompts da tela do checklist

Aula 04 · Copilot no Codespace · um arquivo por vez

  1. Abra este endereço no computador, numa aba ao lado do Codespace.
  2. Toque em Copiar e cole no chat do Copilot.
  3. Leia o que ele fez antes de clicar em Manter (Keep).
  4. Rode a página, teste e só depois passe para o próximo arquivo.
  5. O script.js é seu: para ele, só os prompts de dica e de erro.

1️⃣ index.html: a estrutura

Prompt do HTML
Estou criando a tela de um checklist de inspeção de equipamentos de mineração, para usar no celular.
Crie SÓ o arquivo index.html, sem CSS e sem JavaScript dentro dele.
A tela deve ter:
- um select com id equipamento: "Escolha o equipamento" (com value vazio), CAM-07 Caminhão, ESC-02 Escavadeira e PC-03 Pá carregadeira, com o value igual ao código (CAM-07, ESC-02, PC-03);
- 5 itens, cada um com dois botões de rádio, Conforme e Não conforme: Freios, Pneus, Cinto de segurança, Limpeza da cabine e Nível de combustível;
- o rádio de cada item com o name igual ao nome do item, sem acento e minúsculo (freios, pneus, cinto, limpeza, combustivel);
- o value dos rádios: conforme e nao-conforme;
- um botão Finalizar com id finalizar e um parágrafo vazio com id resultado;
- o link para style.css no head e o script.js no fim do body.
Não coloque comentários: eu mesmo vou comentar.

2️⃣ style.css: a aparência

Prompt do CSS
No meu checklist (#index.html), crie SÓ o arquivo style.css.
Pense primeiro no celular: letra grande, um item embaixo do outro, botões e opções fáceis de tocar com luva.
Deixe a tela bonita e moderna: cores combinando, cantos arredondados e espaço entre os itens.
Em telas a partir de 700px, centralize o conteúdo com largura máxima de 600px.
Destaque o resultado: verde para a classe apto e vermelho para a classe inapto.
Não mude o index.html. Não coloque comentários: eu mesmo vou comentar.

💡 script.js: peça uma dica, não o código

O script.js você escreve sozinho. Travou numa etapa? Troque o que está entre < >.

Prompt de dica
Estou aprendendo JavaScript e escrevendo sozinho o script.js do meu checklist (#index.html #script.js).
Estou na etapa: <o que você quer fazer, ex.: ler o rádio marcado dos Freios>.
O que eu tentei: <o que você fez e o que aconteceu>.
NÃO escreva o código nem mude os meus arquivos.
Me dê só uma dica curta, em até 3 linhas, do próximo passo.

🩺 Deu erro? Peça a explicação assim

Antes, leia o erro no Console (F12) e tente achar a linha. Troque o que está entre < >.

Prompt de erro
No meu checklist, o Console mostra este erro:
<cole aqui a frase vermelha do Console>
Ele aparece quando eu <o que você fez: abri a página, cliquei em Finalizar...>.
Explique a causa em até 2 linhas e diga em qual linha está.
NÃO corrija o código: eu mesmo corrijo.

O Copilot Free tem 50 mensagens de chat por mês. O HTML e o CSS gastam 2 ou 3: guarde o resto para as dicas.
