JavaScript vs C#

Você já viu esses 5 conceitos em JavaScript. A lógica é a mesma — o que muda é a sintaxe. Compare:

Criar variável

JavaScript
let idade = 10;
C#
int idade = 10;

Em C# toda variável precisa de um tipo antes do nome (int, double, string...). Em JS, não.

Criar constante

JavaScript
const nome = "Ana";
C#
const string nome = "Ana";

Mesma ideia (valor que nunca muda depois de criado) — só que em C# a constante também precisa do tipo.

Criar função

JavaScript
function somar(a, b) {
  return a + b;
}
C#
static int Somar(int a, int b) {
  return a + b;
}

Em C# você declara o tipo de CADA parâmetro e também o tipo que a função retorna (aqui, int).

If / else

JavaScript
if (idade >= 18) {
  console.log("Maior");
} else {
  console.log("Menor");
}
C#
if (idade >= 18) {
  Console.WriteLine("Maior");
} else {
  Console.WriteLine("Menor");
}

A lógica do if/else é idêntica — só troca console.log por Console.WriteLine.

Laço de repetição

JavaScript
for (let i = 0; i < 5; i++) {
  console.log(i);
}
C#
for (int i = 0; i < 5; i++) {
  Console.WriteLine(i);
}

Também quase idêntico: troca let por int e console.log por Console.WriteLine.
